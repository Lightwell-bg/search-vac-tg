# Материалы для профиля

Сюда кладутся файлы, по которым строится профиль исполнителя (для оценки вакансий и генерации откликов):

- резюме: `resume.pdf` / `resume.docx` / `resume.md`;
- портфолио (PDF, md);
- README проектов;
- описания кейсов;
- `links.txt` со ссылками (GitHub, сайт, профили).

## Поддерживаемые форматы

`md`, `txt`, `pdf`, `docx`. OCR нет: отсканированные PDF (без текстового слоя) пропускаются.

## Дополнительные пути

`materials/extra_paths.txt` — список дополнительных абсолютных путей к файлам или папкам, которые нужно включить в профиль. Один путь на строку, строки с `#` — комментарии. Несуществующие пути пропускаются.

## Приватное

Файлы в `materials/private/` игнорируются git (не попадают в репозиторий).

## Пересборка профиля

После добавления или изменения файлов выполните:

```bash
python scripts/rebuild_profile.py
```
