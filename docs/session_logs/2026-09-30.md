## 2. Реализация MVP

Ядро (писал сам):
- `src/telegram/parser.py` — нормализация (NFKC, декоративные разделители), извлечение контактов (@username, t.me, email, телефон, URL, bot deep-link), бюджета, ключ дедупликации.
- `src/filtering/rules.py` — правила из `config/filter.yaml`; hard reject только если есть негатив и нет ни одного позитива («n8n для дизайн-агентства» проходит).
- `src/filtering/deduplicator.py` — `channel+msg_id` → SHA256 → RapidFuzz.
- `src/jev/client.py`, `classifier.py` — HTTP-адаптер JEV; 3 вопроса (decision / fit / category); low confidence или противоречие fit/decision → REVIEW.
- `src/llm/openrouter.py` — review и генерация отклика; модель из `OPENROUTER_MODEL`.
- `src/filtering/scorer.py`, `pipeline.py` — rules → JEV → OpenRouter только для REVIEW/ошибки JEV → решение → контакт → уведомление.
- `src/telegram/contact_resolver.py` — прямой контакт, URL-кнопки, одна callback-кнопка; любая оплата → `paid_contact`.
- `src/telegram/client.py`, `listener.py`, `src/main.py` — Telethon (без вступления в каналы), polling + события.

Через исполнителей (Sonnet, маршрут через `jev-route.sh`):
- каркас: config, SQLite/SQLAlchemy, `.env`/`.env.example`, Docker, `.gitignore`;
- aiogram-бот (карточки, 👍/👎, ✍️ отклик), profile builder, скрипты `telegram_login.py`, `stats.py`, `dry_run.py`, `rebuild_profile.py`;
- тесты (216 → 233), README/README_RU/QUICK_START/architecture/PROMPTS.

Профиль: 54 технологии, 34 проекта, `provisional: false`.

`dry_run` на 8 примерах (реальный JEV + OpenRouter): 3 отсеяно правилами, JEV обработал 5 (4 accept, 1 review), OpenRouter вызван 1 раз, 3 уведомления.

## 7. Codex-ревью «Управление из бота»

Все 7 замечаний исправлены, на каждое добавлен регрессионный тест (`tests/test_review_fixes.py`).

1. (High) Миграция реактивировала старые каналы → при одноразовой миграции (`channels_seeded`) строки вне включённого channels.yaml отключаются, строки из yaml берут его `click_callbacks`.
2. (Medium) `click_allowed` разрешал неизвестные/удалённые каналы → по умолчанию False и требуется enabled; `poll_once` проверяет `is_enabled` перед каждым сообщением и прерывает пакет без сдвига курсора.
3. (Medium) Сид при старте гонялся с операциями бота → `listener.setup()` завершается до запуска бота (`run_loop` отдельно), сид/резолв под `_lock`, `upsert_channel` устойчив к IntegrityError (перечитывает и обновляет).
4. (Medium) Paused-строки морили ретраи → при паузе статусы ACCEPTED/NOTIFY_ERROR/NOTIFYING исключаются прямо в SQL-запросе, NEW/JEV_UNAVAILABLE/LLM_ERROR продолжают ретраиться.
5. (Medium) Смена `high_fit_score` не влияла на карточки → `build_card` получает `runtime_settings` (запасной вариант `settings`).
6. (Medium) Могильники удалённых каналов по username → хранятся peer id в `deleted_channel_ids`, сид сравнивает разрешённый id; add_channel снимает могильник; старый список usernames остаётся запасным.
7. (Low) `flush_backlog` ограничен 20 пакетами → цикл до пустого результата с защитой от отсутствия прогресса (0 обработано или тот же набор id).
